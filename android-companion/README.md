# JX手游助手安卓配套

最低 Android 15（API 35），手机和平板通用，USB 连接。App 图标使用用户提供的 JX.png。

## 使用

1. 安装 `JXZS-Android-1.0.0.apk`，打开 App，允许“显示在其他应用上层”。
2. 点击“启动鼠标服务”。USB 连接电脑，手机允许 USB 调试。
3. 使用包含安卓配套功能的新版 `JXZS.exe`，云端会员验证通过后连接设备。
4. 点击电脑投屏窗口，按 Esc 下方、数字 1 左边的 `· / \`` 键显示鼠标。
5. 移动电脑鼠标同步手机箭头。左键点击、按住左键拖动。再次按该键隐藏，恢复原按键映射。

鼠标模式暂时停止游戏映射并释放已按下的触点，防止左键同时开火和点击。退出鼠标模式后恢复之前的映射状态；FPS 模式按原绑定重新进入。App 未运行时不占用此快捷键。

USB 断开、会员失效、离开投屏窗口、缩放中、锁屏时鼠标隐藏。设备旋转时等两端方向一致后重新显示。手机端不注入点击，不连接公网，不接受其他 App 的鼠标连接；输入始终走电脑端原有会员验证和控制通道。

## 开发

JDK 17、Gradle 8.11.1、Android SDK 35。`./gradlew testReleaseUnitTest lintRelease assembleRelease`。
release 签名使用私有 PKCS12，`JXZS_KEYSTORE_PATH` / `JXZS_KEYSTORE_PASSWORD` 通过环境注入，密钥不入仓库。CI 完成 Android 15 模拟器安装、USB 转发握手、显隐、坐标及心跳过期验收。

已知限制：Android 系统的密码/授权等安全窗口可能禁止其他 App 的悬浮窗；服务需用户启动。实机 OEM 系统、电池管理和游戏触摸兼容性需使用实际设备确认。
